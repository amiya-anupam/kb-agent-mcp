setup.py runs 10 steps: checks Python, installs deps, configures .env, runs generate.py, installs the knowledge-qa skill to ~/.bob/, prewarms the uv package cache (so uv run --offline works on first use), and installs the knowledgebase-install skill.

③ Knowledge-QA Skill — Ingest & Security (on demand)
Triggered when you ask Bob to answer questions about files in ~/Desktop/KnowledgeBase/. Runs entirely as a Bob skill — separate from the agent query flow above.
0
network_audit.py — connectivity probe
Checks internet reachability + detects cloud LLM. Emits BLOCK / CAUTION / OFFLINE status + a randomized acknowledge_token.
↓ BLOCK → stop; CAUTION → warn + continue; OFFLINE → continue silently
1
ingest.py — text extraction (23 formats)
Reads every file in KnowledgeBase recursively. Skips symlinks + .noindex-marked folders.
Formats: PDF, DOCX, XLSX/XLS, PPTX, TXT/MD/CSV, .boxnote, HTML, RTF, JSON, YAML, XML, EPUB, EML, PNG/JPG/GIF/WEBP
Output: JSON array — each entry: { file, type, chars, text, confidential, confidential_reason }
→
uv run
Confidentiality classification
Checks EML Sensitivity header → PDF metadata → DOCX core props → filename → text body. Never redacts — flags only.
↓ if confidential:true entries found
2
Consent gate (Step 2b in SKILL.md)
🔒 Flagged files listed to user before any content enters LLM context.
User chooses: yes (include all) · no (exclude all) · 1,2… (include specific).
Runs even in offline/local LLM mode — separate from the network BLOCK gate.
↓ approved content loaded into Bob context
3
Bob (Claude) — Q&A over your documents
Holds all approved text fields in context. Answers questions with citations. Never re-runs ingest unless user requests refresh.
④ Passthrough mode — when Ollama is not running
agent_base retrieves context
uses offline sentence-transformers embeddings (no LLM) · reads README or *_index.json
→
emit_passthrough()
prints <<<KB_PASSTHROUGH>>> block to stdout with retrieved context snippets
→
Bob (Claude)
reads the passthrough block · generates the answer using provided context
Privacy: your raw documents never leave your machine. Only the retrieved text snippets (a few paragraphs) are sent to Claude in passthrough mode. When a local LLM is running, nothing goes to Claude at all.
