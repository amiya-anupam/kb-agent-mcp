## 3. Setup Flow — Run Once

```
User runs: python3 scripts/setup.py
     │
     ▼
scripts/setup.py
   1. Check Python version (≥ 3.10 required)
   2. pip install -r requirements.txt
   3. Prompt for KB_ROOT folder (or use --kb-root flag)
   4. Prompt for LLM provider + model (or default to Ollama passthrough)
   5. Write .env from choices (if not present)
   6. Verify at least one knowledge folder exists in KB_ROOT
   7. Run scripts/generate.py (see below)
   8. install_install_skill() — copies skills/knowledgebase-install/ → ~/.bob/
     │
     ▼
scripts/generate.py
  1. Discover top-level subfolders via embeddings.discover_folders()
     - Excludes: agents, .git, __pycache__, .venv, .bob, node_modules, dist, build
     - Excludes any folder in KB_IGNORE_FOLDERS env var
     - Must contain at least one indexable file (.pdf, .docx, .pptx, .xlsx, .md, .txt, .csv, .boxnote)
  2. For each domain folder:
     a. Build / update vector index (embeddings.build_index)
     b. LLM-generate a 1-line folder description
     c. LLM-generate per-file summaries (capped at KB_BUDGET_SUMMARY chars each)
     d. Build domain_meta.json entry
  3. Write agents/vector_store/domain_meta.json
  4. Write ~/.bob/skills/knowledgebase-agent/SKILL.md
     (trigger phrases + python3 invocation command)
```

## 4. Confidentiality Classification Pipeline

`_classify_confidentiality()` in `ingest.py`. Called per file after text extraction. Returns `(bool, reason_str)`.

### Signal sources (checked in priority order, first match wins)

| Priority | Source | How checked |
|---|---|---|
| 1 | EML `Sensitivity` header | Exact header value from `msg.get("Sensitivity")` — matches: `confidential`, `company-confidential`, `personal`, `private`, `restricted` |
| 2 | PDF metadata | `reader.metadata["/Keywords"]` and `reader.metadata["/Subject"]` — scanned with `_CONFIDENTIAL_RE` |
| 3 | DOCX core properties | `doc.core_properties.category` and `.keywords` — scanned with `_CONFIDENTIAL_RE` |
| 4 | File path / filename | `str(path).lower()` — scanned with `_CONFIDENTIAL_RE` |
| 5 | Extracted text body | `capped_text` — scanned with `_CONFIDENTIAL_RE`, first match only |

### `_CONFIDENTIAL_RE` keyword list (16 terms, case-insensitive, compiled once)

```
confidential · internal use only · not for distribution · not for sharing ·
do not share · do not distribute · proprietary · restricted · privileged ·
ibm confidential · company confidential · for internal use · classification: ·
sensitive · top secret · private and confidential
```

### `.noindex` sentinel — hard exclusion

- Pre-computed before the `rglob` loop: `_noindex_dirs = { p.parent.resolve() for p in FOLDER.rglob(".noindex") if not p.is_symlink() }`
- `_in_noindex_folder(file_path)`: walks `file_path.resolve().parents`, returns `True` if any ancestor is in `_noindex_dirs`
- Hard-excluded files never appear in JSON output, never reach the consent gate

### Tuple extractor protocol

Three extractors return `(text, meta)` rather than plain `str` so their format-native metadata reaches the classifier:

| Extractor | Returns | Meta used by classifier |
|---|---|---|
| `extract_pdf()` | `(text, {keywords, subject})` | PDF info dict fields |
| `extract_docx()` | `(text, {category, keywords})` | `core_properties` fields |
| `extract_eml()` | `(text, sensitivity)` | Raw `Sensitivity` header string |

`_TUPLE_EXTRACTORS = {".pdf", ".docx", ".eml"}` — dispatch loop unpacks these; all others receive plain `str`.

## 6. Query Flow — Every Question

This flow is the **agent subprocess** (`agent_knowledgebase.py`), invoked by Bob or directly via CLI.

```
python3 agents/agent_knowledgebase.py "question" [--format table|bullets|oneline|...]
     │
     ▼
agent_knowledgebase.ask_knowledgebase(question, format_flag)
     │
     ├─ 1. load_domain_meta()   → reads domain_meta.json
     │
     ├─ 2. get_history()        → reads session_memory.json (memory.py)
     │
     ├─ 3. detect_format_intent(question, format_flag)
     │       explicit --format flag wins over NL phrase detection
     │       NL patterns detected: table, bullets, oneline, numbered, json, paragraph
     │       returns (clean_question, format_instruction_str)
     │
     ├─ 4. _keyword_confidence(question, domains)
     │       Count keyword hits per domain from domain_meta["keywords"]
     │       Confident conditions (either):
     │         (a) exactly 1 domain matched AND ≥2 keyword hits
     │         (b) one domain has >=3x more hits than every other match
     │             (dominant-match rule — prevents wrong routing for
     │              multi-product queries like "ACE and CP4I revenue")
     │
     │     ┌─ confident = True ─────────────────────────────────────────────────┐
     │     │  domain_names = [single matched domain]                            │
     │     │  (no LLM call — O(n) keyword scan only)                           │
     │     └───────────────────────────────────────────────────────────────────┘
     │
     │     ┌─ confident = False ────────────────────────────────────────────────┐
     │     │  classify_intent(question, history, domains)                       │
     │     │    If _PASSTHROUGH: skip LLM → keyword fallback                   │
     │     │    Else: LLM call with domain descriptions + file summaries        │
     │     │    Returns { domains, needs_clarification, clarification_question }│
     │     │    If needs_clarification → return clarification question          │
     │     └───────────────────────────────────────────────────────────────────┘
     │
     ├─ 5. run_agents_parallel(domain_names, question, history, format_instruction)
     │       1 domain  → call_sub_agent() directly (no thread overhead)
     │       N domains → ThreadPoolExecutor(max_workers=N)
     │                   as_completed() — results collected in completion order
     │
     │         call_sub_agent(domain, question, history, format_instruction)
     │           → reads domain_cfg from domain_meta.json
     │           → checks for agents/agent_<safe>.py (per-domain file)
     │               present  → importlib loads module → module.domain_ask()
     │               absent   → _build_system_prompt(domain_cfg)
     │                           _apply_format_instruction(prompt, format_instruction)
     │                           agent_base.ask(question, folder_name, ...)
     │
     ├─ 6. merge_answers(results, domains)
     │       no found results → "couldn't find" message + domain hints
     │       passthrough results → concatenate <<<KB_PASSTHROUGH>>> blocks
     │       1 found result → answer + confidence_footer
     │       N found results → ### From <agent>\n\n<answer> --- separated
     │
     └─ 7. add_turn(question, answer) → memory.py → session_memory.json
```

## 7. LLM Provider Decision Tree

```
KB_LLM_PROVIDER env var
     │
     ├─ "anthropic" ──────────────────────────────► _call_anthropic()
     │                                               POST KB_LLM_BASE_URL/v1/messages
     │                                               x-api-key: KB_API_KEY
     │                                               max_tokens: 4096
     │
     ├─ "openai" or "custom" ─────────────────────► _call_openai_compat()
     │                                               POST <base>/chat/completions
     │                                               Authorization: Bearer KB_API_KEY
     │                                               Auto-appends /v1 for port 11434 base URLs
     │
     └─ "ollama" (default) ───────────────────────► _call_ollama()
                                                     POST KB_LLM_BASE_URL/api/chat
                                                     model: KB_MODEL (default: qwen3:14b)
                                                     think: false
                                                     num_ctx: from context_budget

passthrough mode override (_PASSTHROUGH constant, evaluated once at import):
  KB_LLM_PROVIDER = "passthrough"  → always passthrough
  KB_LLM_PROVIDER = "ollama" + no API_KEY + Ollama unreachable + KB_PASSTHROUGH_FALLBACK ≠ "false"
    → _is_passthrough_mode() probes http://localhost:11434/api/tags (3s timeout)
    → returns True if status ≥ 400 or connection fails
```

## 8. Embedding Backend Decision Tree

```
get_embedding(text)  [embeddings.py]
     │
     ├─ KB_LLM_PROVIDER = "passthrough" ─────────► _embed_sentence_transformers()
     │                                               SentenceTransformer("all-MiniLM-L6-v2")
     │                                               Fully offline once downloaded (~80 MB)
     │
     ├─ KB_LLM_PROVIDER in (openai, anthropic, custom)
     │     → _embed_openai()
     │       POST KB_LLM_BASE_URL/embeddings
     │       model: KB_EMBED_MODEL or "text-embedding-3-small"
     │       on failure → fallback to sentence-transformers
     │
     └─ KB_LLM_PROVIDER = "ollama" (default)
           → _embed_ollama()
             POST KB_LLM_BASE_URL/api/embeddings
             model: KB_EMBED_MODEL (default: nomic-embed-text)
             text capped at context_budget.get("embed_chars") [default 8000]
             on failure → fallback to sentence-transformers
```

## 9. README-First vs RAG Strategy Decision

`agent_base.ask()` — runs per domain per question.

```
ask(question, folder_name, ...)
     │
     ├─ _is_data_question(question)?    ← NEW: checked before README lookup
     │     Matches patterns like: revenue, ARR, MRR, ACV, TCV, quota,
     │     attainment, how much, how many, what is the [number|total|sum],
     │     list all, show me all, breakdown, by [quarter|region|geography],
     │     Q[1-4] 20XX, YTD, YoY, QoQ, trailing, rolling, R4Q
     │     │
     │     ├─ Yes → return (None, "") immediately                              ┐
     │     │        skip README entirely — go straight to Raw-file RAG        │
     │     │                                                                   │
     │     └─ No  → continue to README lookup below                           │
     │                                                                         │
     ├─ _get_readme_context(folder_name, question)                             │
     │     _find_readme(folder):                                               │
     │       Priority 1: any .md with "readme" in name (case-insensitive)     │
     │       Priority 2: <FolderName>.md exactly                              │
     │       Priority 3: first .md with a # heading in first 500 chars        │
     │       Priority 4: first .md file found                                 │
     │                                                                         │
     │     README found?                                                       │
     │     │                                                                   │
     │     ├─ No  ──────────────────────────────────────────────────────────┐ │
     │     │                                                                 │ │
     │     └─ Yes → _non_index_chars(readme_text) ≥ KB_MIN_README_CHARS?    │ │
     │                                                                       │ │
     │           No (< 200 chars of hand-written content) ──────────────────┤ │
     │                                                                       │ │
     │           Yes → _is_complex_question(question)?                      │ │
     │                   patterns: compare, walk me through, architecture,  │ │
     │                   deep dive, pros and cons, trade-off, full          │ │
     │                   breakdown, how does X work, comprehensive, ...     │ │
     │                                                                       │ │
     │               Complex → context_budget.trim(readme_text,"full_readme")│ │
     │                          up to 24,000 chars                          │ │
     │                                                                       │ │
     │               Simple  → _extract_auto_index_block(readme_text)      │ │
     │                          context_budget.build_context(pre_index,block)│ │
     │                          compacted: strip boilerplate, collapse      │ │
     │                          groups, normalise to 2-col table, trim      │ │
     │                          up to 8,000 chars total                     │ │
     │                                                                       │ │
     ├─ README context obtained → call_llm() or emit_passthrough()          │ │
     │   source score = 1.0 (authoritative — no retrieval uncertainty)      │ │
     │   confidence_footer shows "📄 Source: <readme name>"                 │ │
     │                                                                       │ │
     └─ No README / thin README / data question bypass ─────────────────────┘─┘
           Raw-file RAG fallback:
           embeddings.search(question, folder_name, top_n=domain_cfg.top_n)
           → cosine similarity against vector index
           → extract_full_text() per result (up to max_chars per file)
               XLSX/XLS: check VECTOR_STORE index cache first
                 cache hit (summary > 200 chars) → return cached aggregation instantly
                 cache miss → single-pass streaming aggregation:
                   detect revenue column + group-by cols (Year, Quarter, Geography, …)
                   stream all rows once, emit pre-aggregated totals by dimension
           → call_llm() or emit_passthrough()
           source score = cosine similarity (0.0–1.0)
           confidence_footer shows "🎯 Confidence: High/Medium/Low (score)"
```

## 10. Passthrough Mode Data Flow

When no local LLM is available. `_PASSTHROUGH` is computed once at import time in `agent_base.py`.

```
agent_base.ask() detects _PASSTHROUGH = True
     │
     ▼
emit_passthrough(question, context, system_prompt, agent_name, source_label)
     │
     ▼
Prints to stdout:
  <<<KB_PASSTHROUGH>>>
  AGENT: <agent_name>
  QUESTION: <question>
  SOURCE: <source_label>
  SYSTEM_PROMPT:
  <system_prompt>
  ---CONTEXT---
  <retrieved context>
  <<<KB_PASSTHROUGH_END>>>

     │
     ▼
agent_knowledgebase.merge_answers()
  Detects r.get("passthrough") = True
  Returns concatenated block(s) as the answer string

     │
     ▼
Bob / Claude reads entire subprocess stdout
  Parses <<<KB_PASSTHROUGH>>> ... <<<KB_PASSTHROUGH_END>>> blocks
  Answers the question using the embedded context
  Returns answer to user
```

## 11. Watcher Daemon Event Handling

`scripts/watch_kb.py` — filesystem watcher using `watchdog`. Runs as a background daemon.
Timeout for the `generate.py` subprocess is configurable via `KB_GENERATE_TIMEOUT` (default: 900 s).

```
watch_kb.py starts
  → Loads context_budget.COLLAPSE_RULES (same rules as query-time compaction)
  → Starts watchdog observer on KB_ROOT

File event received
     │
     ├─ Created / Modified
     │     extension in INCLUDE_EXTS?
     │     ├─ No  → ignore
     │     └─ Yes → embeddings.update_index_for_file(folder_name, file_path)
     │               hash check → skip if unchanged
     │               re-embed and update index entry
     │               → trigger README re-generation for the folder
     │                 (re-runs LLM summarisation for changed file)
     │
     ├─ Deleted
     │     → embeddings.remove_from_index(folder_name, file_path)
     │       removes entry from <domain>_index.json
     │
     └─ Directory deleted
           → embeddings.delete_index(folder_name)
             deletes entire <domain>_index.json

Stale file alert (configurable threshold):
  File modified time > KB_STALE_DAYS (default: 90) days ago
  → Adds stale alert annotation to README AUTO-INDEX block
```

## 12. Memory & Session Lifecycle

`agents/memory.py` — all state in `agents/vector_store/session_memory.json`.

```
session_memory.json schema:
{
  "messages": [
    {"role": "user",      "content": "..."},
    {"role": "assistant", "content": "... (truncated to MAX_ANSWER_CHARS)"},
    ...
  ],
  "last_active": 1720000000.0   ← Unix timestamp, updated on every add_turn()
}

Session lifecycle:
  load() called: last_active > TIMEOUT_HOURS (default 2h) ago → auto-reset to empty
  add_turn(): appends user+assistant pair
              answer truncated to MAX_ANSWER_CHARS (default 400) before persisting
              total kept: MAX_TURNS × 2 messages (default 20 turns = 40 messages)
  clear():     resets messages to [], called by --clear CLI arg or "clear" command
  get_history(): returns messages list for conversation context injection
  summary():   human-readable "N turns, last active X min ago"

History injection into LLM calls:
  agent_base.ask() → messages.extend(history[-context_budget.get("history"):])
  classify_intent() in orchestrator → messages.extend(history[-4:])   (fixed 4 turns)
```

## 13. Token Budget Engine

`agents/context_budget.py` — single source of truth for all char/token limits. Imported by `agent_base.py`, `embeddings.py`, and `watch_kb.py`.

### Budget registry (all overridable via env vars)

| Key | Env var | Default chars | ~Tokens | Usage |
|---|---|---|---|---|

### Compaction functions

`compact_index_block(block)` — applied at query time to the `<!-- KB:AUTO-INDEX:START/END -->` markdown block:
1. Strip heading boilerplate (`## 📁 Folder Index`, count line, `_Indexed:` line)
2. Strip size annotations (`&nbsp; _PDF_ &nbsp; X MB`)
3. Normalise multi-column table → 2 columns (File | Summary)
4. Collapse repeated-version file groups via `COLLAPSE_RULES`
5. Truncate per-row summaries to `KB_BUDGET_SUMMARY`
6. Clean up consecutive blank lines from deletions

`COLLAPSE_RULES` — shared between `compact_index_block()` (query-time) and `watch_kb.py` (index-time). Configurable via `KB_COLLAPSE_PATTERNS` env var (pipe-separated triples: `pattern|label|template`).

## 14. Security Architecture

### ingest.py hardening

| Control | Implementation | Guards against |
|---|---|---|
| Path traversal | `_validate_folder()` — resolves path, checks against `ALLOWED_ROOTS` (reads `KB_ROOT` from `.env`; falls back to `~/Desktop/KnowledgeBase`). `sys.exit(2)` on failure | Malicious `--folder` argument escaping KB root |
| Symlink traversal | `if f.is_symlink(): continue` in `rglob` loop | Symlinks pointing outside the allowed root |
| XML bomb / XXE | `defusedxml.ElementTree` replaces `xml.etree.ElementTree` | Billion Laughs attack, quadratic blowup, XXE injection |
| Image memory bomb | `path.stat().st_size > MAX_IMAGE_MB * 1024 * 1024` → skip before `read_bytes()` | Decompression of large images exhausting RAM |
| EML recursion bomb | `part_count > MAX_MIME_DEPTH (50)` → truncate with sentinel | Deeply nested multipart MIME structures |
| Error leakage | `_sanitize_error(e)` — strips absolute paths, truncates to 200 chars | Internal paths / stack traces entering LLM context |
| Aggregate context cap | `total_chars >= MAX_TOTAL_CHARS (10,000,000)` → break with TRUNCATED sentinel | Unbounded token inflation from large KB |
| .noindex sentinel | Pre-computed `_noindex_dirs`; `_in_noindex_folder()` per-file check | Entire off-limits directories bypassing consent gate |

### network_audit.py hardening

| Control | Implementation | Guards against |
|---|---|---|
| Per-socket timeout | `s.settimeout(timeout)` on the probe socket | Global `socket.setdefaulttimeout()` side effects on other threads |
| Randomised ack token | `secrets.token_hex(4).upper()` — new value each run | Prompt-injection attacks embedding a fixed bypass phrase in document content |
| Token source check | SKILL.md rule: token only accepted from live user message, never from ingested document | Malicious document containing the ack token to auto-acknowledge the BLOCK warning |
| Exit code 1 on BLOCK | `sys.exit(1 if active_blocks else 0)` | Scripted bypasses that ignore the printed warning |

### SKILL.md consent gate

| Control | Behaviour |
|---|---|
| Confidential consent gate (Step 2b) | Pauses before context load when any `confidential:true` entry exists; awaits yes/no/numbered user choice |
| Excluded file guard (Step 4) | Never reproduces text from excluded entries, even on direct user request |
| 🔒 citation prefix | All answers from confidential-flagged files prefixed with 🔒 so user always knows the source sensitivity level |

## 15. Data Classification — What Leaves Your Machine

| Operation | Destination | Condition | Mitigations |
|---|---|---|---|
| `ingest.py` text extraction | Nowhere | Always | 100% local Python — no sockets opened |
| `network_audit.py` probe | `8.8.8.8:53` TCP (Google DNS) | Once per session | Only tests connectivity, no data sent |
| `uv` package install | PyPI (`pypi.org`, `files.pythonhosted.org`) | First run only | Pass `--offline` after first cache |
| Embedding call (Ollama) | `localhost:11434` | At index build time | Local only — never leaves machine |
| Embedding call (OpenAI/custom) | Cloud API endpoint | When `KB_LLM_PROVIDER ≠ ollama` | File text snippets (~2000 chars) sent |
| LLM call (Ollama) | `localhost:11434` | Every query | Local only |
| LLM call (cloud) | `api.anthropic.com` / `api.openai.com` | When `KB_LLM_PROVIDER ≠ ollama` | **Document content sent in full** |
| Passthrough context block | Bob/Claude cloud API | When Ollama unreachable | **Document context sent to cloud** — user warned by BLOCK gate |
| Web search (Tavily) | `api.tavily.com` | Only if Bob explicitly calls web-search tools | Query sent, not document content |
| HTML viewer (`open` command) | Local browser (`file://`) | When user asks to view HTML file | No network request — file:// local only |

## 19. MCP Package — kb-agent-mcp

A pip-installable Python package that exposes the same knowledge base as an MCP server.
Install with `pip install -e .` (editable) or `pip install kb-agent-mcp`.

### Package layout

```
kb_agent_mcp/
  __init__.py          ← version string (0.1.0)
  config.py            ← frozen Config dataclass; reads .env + env vars at import time
  context_budget.py    ← token/char budget engine (mirrors agents/context_budget.py)
  file_parser.py       ← async multi-format extractor (PDF, DOCX, PPTX, XLSX, MD, TXT, …)
  embeddings.py        ← async embedding backends: Ollama / OpenAI-compat / sentence-transformers
  vector_store.py      ← ChromaDB persistent client; replaces agents/vector_store/*.json files
  memory.py            ← async multi-session memory; stored under {KB_ROOT}/.kb_index/session_memory/
  base_agent.py        ← async README-first RAG pipeline; mirrors agents/agent_base.py
  domain_rules.py      ← DomainConfig dataclass; loads domain_config.yaml; apply_pin_rules()
  domain_agent.py      ← DomainAgent class; build_all_domain_agents()
  orchestrator.py      ← async keyword routing + LLM classifier; parallel domain dispatch; merge
  server.py            ← FastMCP server; exposes 5 tools; stdio + HTTP/SSE transport
  cli/
    setup.py           ← kb-agent-setup   interactive wizard (.env creation)
    generate.py        ← kb-agent-generate  LLM → domain_config.yaml + ChromaDB index + SKILL.md
    watch.py           ← kb-agent-watch    async watchdog (watchdog library)
```

### MCP tools exposed

| Tool | Signature | Description |
|---|---|---|
| `ask` | `ask(question, format="", session_id="default")` | Main query — routes to one or more domains, returns merged answer |
| `list_domains` | `list_domains()` | Returns domain names + descriptions from ChromaDB metadata |
| `reindex` | `reindex()` | Full rescan of KB_ROOT — rediscovers folders, rebuilds ChromaDB collections |
| `clear_memory` | `clear_memory(session_id="default")` | Clears conversation history for the given session |
| `show_memory` | `show_memory(session_id="default")` | Returns current session turns |

### CLI entry points

| Command | Entry point | Purpose |
|---|---|---|
| `kb-agent-setup` | `kb_agent_mcp.cli.setup:main` | Interactive first-run wizard |
| `kb-agent-generate` | `kb_agent_mcp.cli.generate:main` | LLM domain config + index build |
| `kb-agent-serve` | `kb_agent_mcp.server:main` | Start MCP server (`--transport http` for HTTP/SSE) |
| `kb-agent-watch` | `kb_agent_mcp.cli.watch:main` | Start filesystem watcher |

### Key differences from the legacy agents/ system

| Feature | Legacy (`agents/`) | MCP package (`kb_agent_mcp/`) |
|---|---|---|
| Vector store | JSON files in `agents/vector_store/` | ChromaDB under `{KB_ROOT}/.kb_index/chroma/` |
| Domain config | `domain_meta.json` + per-domain `agent_<x>.py` | `domain_config.yaml` per folder |
| LLM calls | Sync (`httpx` + blocking) | Async (`asyncio.to_thread` + `httpx`) |
| Transport | Subprocess stdout | MCP stdio or HTTP/SSE (FastMCP) |
| Session memory | Single shared `session_memory.json` | Per-session files; `session_id` param |
| Domain config generation | `scripts/generate.py` (auto, no user review) | `kb-agent-generate` (LLM-generated YAML → Accept/Skip prompt) |
