② Setup Flow (run once, or on new folder)
python3 generate.py
1
generate.py
Loads .env, resolves KB_ROOT, discovers top-level folders with indexable files
2
generate.py → embeddings.py
Calls build_index(folder) for each domain — reads every file, chunks text, calls Ollama embed → writes *_index.json
Offline: sentence-transformers used as fallback if Ollama unreachable
3
generate.py → Ollama (qwen3:14b)
Samples filenames/snippets per folder → asks LLM for description + 10-15 keywords → writes domain_meta.json
4
generate.py
Creates README stubs for any domain folder that has no README yet (LLM-authored or minimal fallback)
No per-domain agent .py files generated — orchestrator reads domain_meta.json dynamically at query time
5
generate.py
Writes agents/SKILL.md + auto-copies to ~/.bob/skills/knowledgebase-agent/SKILL.md
Bob reads this file at skill-detection time — tells it the exact python3 command to run
6
watch_kb.py
Already running. Builds AUTO-INDEX block for each folder's README using LLM-generated per-file summaries
This is the primary context source for all future queries
③ Watcher — What happens when you add/change a file
watch_kb.py (always running as launchd daemon)
1
watchdog (OS FSEvents)
OS delivers filesystem event to KBHandler.on_created / on_modified / on_deleted / on_moved
2
KBHandler
Debounces event (5s). Schedules: index update + README update for the affected folder
New top-level folder → schedules generate.py run instead
3
embeddings.update_index_for_file()
Extracts text from changed file → embeds → upserts entry in *_index.json
4
watch_kb → Ollama (qwen3:14b)
Generates one-sentence summary for changed file → used to rebuild README AUTO-INDEX block
Uses text snippet as fallback if LLM unreachable
5
watch_kb → README.md
Rewrites the <!-- KB:AUTO-INDEX:START --> block in the folder's README with the updated file table
README writes are filtered from future watchdog events to prevent infinite loops
⚡ Folder deleted → immediately deletes *_index.json + domain_meta entry (no debounce, no generate.py)
⚡ Folder renamed → immediately renames index .json + re-keys domain_meta entry inline
⚡ New folder → debounced 5s → triggers generate.py to build full new domain
④ Knowledge-QA Skill — Ingest & Security Flow
You ask Bob a question about files in ~/Desktop/KnowledgeBase/
0
network_audit.py
Connectivity probe runs first. Detects internet + cloud LLM type.
BLOCK → stop with ⛔ warning + random token gate · CAUTION → ⚠️ notice then continue · OFFLINE → ✅ continue silently
1
ingest.py (via uv run)
Reads KnowledgeBase recursively. Extracts text from 23 formats. Skips symlinks + .noindex folders. Caps at 50k chars/file, 10M chars total.
Each entry → { file, type, chars, text, confidential, confidential_reason }
1b
_classify_confidentiality() — inside ingest.py
Tags each entry: EML Sensitivity header → PDF metadata → DOCX core props → filename/path → text body (first match wins). Never redacts.
2
SKILL.md — Step 2: Inventory report
Bob displays file list. Non-confidential = plain bullet. Confidential = 🔒 prefix + reason.
2b
SKILL.md — Step 2b: Consent gate
If any confidential:true entries: pauses. Lists flagged files. User picks yes / no / numbered subset before content enters LLM context.
Runs even in offline/local-LLM mode — separate layer from the network BLOCK gate above
3
Bob (Claude) — Q&A
Holds approved text fields in context. Answers questions with source citations (🔒 prefix for confidential sources). Excluded files are never reproduced even if asked.
⑤ Query Flow — What happens when you ask Bob a question
You → Bob → agent_knowledgebase.py → answer
1
You (in Bob chat)
Type a question, e.g. "What is the ACE MCP server?"
2
Bob's Claude (cloud)
Reads SKILL.md, detects trigger intent → runs:
python3 agents/agent_knowledgebase.py "What is the ACE MCP server?"
This is the only internet step. Claude does NOT see document content here.
3
agent_knowledgebase.py
Fast keyword route: scans question against keywords in domain_meta.json — O(1), no LLM
4
agent_knowledgebase.py → Ollama (qwen3:14b)
LLM classification: if keyword route ambiguous, asks local LLM to pick the right domain(s)
In passthrough mode (Ollama down): falls back to keyword route only
5
agent_knowledgebase.py → agent_base.ask()
Dispatches directly to agent_base for each matched domain (config from domain_meta.json). Multi-domain? Run in parallel via ThreadPoolExecutor.
No per-domain .py wrapper files — domain config is read from domain_meta.json at runtime
6
agent_base.ask() — README-first RAG
Finds folder README → reads AUTO-INDEX block
• Normal question: uses index block + brief intro (~1-5k tokens)
• Complex question (explain/compare/detail…): uses full README up to 40k chars
• No README: falls back to cosine similarity search over *_index.json
7
agent_base → Ollama (qwen3:14b)
Sends [system_prompt + context + question] to local LLM → gets answer
8
Bob's Claude (cloud)
Reads agent stdout → returns final formatted answer to you
🔄 Passthrough mode (Ollama unreachable): steps 4 + 7 are skipped. Instead, agent_base emits a <<<KB_PASSTHROUGH>>> block containing the retrieved README context to stdout. Bob's Claude reads that block and itself answers the question — still without ever accessing raw document files.
