Retrieval & Context Quality

Hybrid search (keyword + vector) High impact ✓ Shipped vector_store.py

BM25 (rank_bm25) runs in-process per domain alongside ChromaDB ANN vector search. Scores are fused with Reciprocal Rank Fusion before returning the top-N results. The BM25 index is lazily built on first search and invalidated on every upsert/delete.

Implemented in _bm25_search_sync() and _rrf_fuse() · KB_CHUNK_SIZE / KB_CHUNK_OVERLAP env knobs exposed
Chunk overlap & sliding window indexing Medium impact ✓ Shipped vector_store.py

Documents are split into overlapping character-level windows (_CHUNK_SIZE=3500, _CHUNK_OVERLAP=200) so answers near chunk boundaries are never silently dropped. Both values are runtime-configurable via env vars.

Implemented in chunk_text() · each chunk stored as a separate ChromaDB entry · deduplication back to file-level in search
Re-ranker pass after vector search Medium impact ✓ Shipped reranker.py · domain_agent.py

A cross-encoder re-ranker (cross-encoder/ms-marco-MiniLM-L-6-v2 via sentence-transformers) scores every (query, passage) pair in the candidate pool and re-sorts before the final top-N cut. Gracefully degrades when the model is absent.

Opt-out via KB_RERANKER_ENABLED=false · candidate pool size via KB_RERANKER_CANDIDATES · fallback to unranked order on any failure

Data Analyst Capability

Trend & time-series analysis High impact ✓ Shipped analyst/engine.py

The analyst engine detects trend questions ("trend over Q1–Q4", "YoY", "QoQ") and routes them to _trend_pivot(), which emits a period × metric table with optional delta columns. Consistent with the "growth" theme questions already in the planner.

QoQ / YoY delta columns included · handled via include_deltas=True flag
Chart / visualisation output for analyst answers Medium impact ✓ Shipped analyst/engine.py · server.py

Analyst tool responses include a chart_data object with type, labels, datasets, csv (for file attachment), and mermaid (inline single-dataset rendering). Compare responses emit grouped-bar chart data.

query_data() and compare_data() both surface chart_data · Mermaid omitted for multi-dataset comparisons
Multi-file comparison in analyst Medium impact ✓ Shipped analyst/engine.py · server.py

compare_data(path_a, path_b, …) MCP tool loads both files, aggregates each by time period, aligns periods, and returns a diff table (B − A absolute + % change). Supports optional metric_col and time_col overrides.

Exposed as compare_data() MCP tool · grand-total row when multiple periods exist

Memory & Session

Named sessions / workspaces High impact ✓ Shipped memory.py · server.py

Sessions are named by the caller via session_id and persist across server restarts. list_sessions() enumerates all sessions with turn count and last-active time. resume_session() replays a full conversation transcript. HTTP transport auto-generates per-connection UUIDs to prevent session bleed.

list_sessions() and resume_session() MCP tools shipped · KB_DEFAULT_SESSION_ID config for stable personal sessions
Conversation summarisation before truncation Medium impact ✓ Shipped memory.py

Before storing a long answer, add_turn_sync() runs a one-shot LLM call (_compress_answer_sync()) to produce a concise summary. Falls back to sentence-boundary truncation when the LLM is unavailable or times out (8 s wall-clock cap).

Opt-out via KB_MEMORY_COMPRESS=false · automatically skipped in passthrough mode

Domain Management & Indexing

Auto re-index on file change (watcher) High impact ✓ Shipped cli/watch.py

The kb-agent-watch daemon uses watchdog to detect file creates, modifies, and deletes. Modified files call upsert_file(domain, path) directly; deleted files call delete_file(). New top-level folders trigger a full build_collection() and optional domain_config.yaml generation.

Debounced per-file; only the affected domain is re-indexed · macOS launchd auto-start via kb-agent-setup
domain_config.yaml per-domain prompt customisation Medium impact ✓ Shipped domain_rules.py · DomainConfig

DomainConfig exposes a system_prompt_extra field in domain_config.yaml. Domain owners can append custom instructions to the system prompt (e.g. "Always cite the contract reference for BizOps answers") without touching Python.

Loaded in domain_rules.py:171 and appended during system-prompt construction
Image OCR indexing Useful ✓ Shipped file_parser.py

PNG, JPEG, GIF, and WebP files are indexed via pytesseract OCR when installed, falling back to PIL metadata (dimensions, colour mode). Controlled by KB_OCR_ENABLED (default true) and KB_OCR_ENGINE.

Implemented in file_parser._extract_image() · tesseract → PIL fallback chain

Security, Audit & Feedback

Feedback-driven retrieval reweighting Medium impact ✓ Shipped feedback.py · vector_store.py · config.py

After RRF fusion, _search_sync() applies per-file score multipliers derived from feedback.jsonl. High-rated files (≥4★) are boosted up to 1.5×; low-rated files (≤2★) are demoted to a floor of 0.5×. Signals are time-decayed (linear over KB_FEEDBACK_DECAY_DAYS, default 90) and sqrt(n)-dampened to resist early noise. The weight table is cached for 5 minutes and busted immediately on every rate_answer() call.

Opt-out via KB_FEEDBACK_REWEIGHT_ENABLED=false · joins feedback.jsonl + audit.jsonl on answer_hash to recover files_cited
Audit log analytics endpoint Low effort, useful ✓ Shipped audit.py · server.py

audit_summary(days) MCP tool returns a Markdown analytics report: total queries, blocked / failure rate, avg latency, top-10 repeated questions, per-domain query volume, avg star rating, rating distribution, and recent low-rated answers with comments. Reads both audit.jsonl and feedback.jsonl in one call.

Both logs read in parallel via asyncio.gather() · look-back window is configurable (default 30 days, max 365)
.noindex propagation to agents-layer Security gap ✓ Shipped agents/agent_base.py · file_parser.py

The agents-layer agent_base.py now implements its own _has_noindex_ancestor() that mirrors the MCP-layer logic in file_parser.py. Both check for .noindex sentinel files in ancestor directories, closing the bypass path that existed when only the MCP layer enforced the sentinel.

Guard confirmed at agents/agent_base.py:80 · docstring cross-references MCP-layer implementation

Developer & User Experience

Interactive question suggestions at session start UX improvement Pending cli/watch.py · suggest_questions MCP tool

The suggest_questions(path) MCP tool exists and is zero-LLM-cost. The interactive CLI still starts with a generic prompt — wiring suggest_questions() to run on a sample file from each domain at CLI startup and display 3–5 example questions would significantly lower blank-page friction for new users.

kb-agent export — snapshot answers to markdown/PDF Useful for sharing Pending cli/ · audit.jsonl · writeback.py

Teams doing BizOps / renewal-review investigations want to share findings. A kb-agent export --session <id> command that reads the audit log and renders all Q&A pairs for that session to formatted Markdown (or PDF) is not yet implemented. writeback.write_document() already handles safe writes into KB_ROOT — the export could be placed there automatically.

Doctor check: embedding model freshness Operational Shipped cli/doctor.py · embeddings.py · vector_store.py

kb-agent doctor now includes _check_embed_model_mismatch() (check ⑥) which reads the embed_model key stamped into each ChromaDB collection's metadata at index time (via effective_model_name() in embeddings.py) and compares it against the currently configured model. A missing stamp is a soft warning; an actual mismatch is a hard error with a re-index hint. Previous checks renumbered ⑦–⑩.

Architecture / Internals

Unify the dual agent stack Tech debt Pending agents/ vs kb_agent_mcp/

Two parallel implementations still exist: agents/agent_base.py (scripts layer) and kb_agent_mcp/base_agent.py (MCP package). Both implement extract_full_text(), call_llm(), and ask() independently. New features added to the MCP layer (BM25, re-ranker, chunking, OCR, feedback reweighting) are not available via the scripts layer until migrated. ARCHITECTURE.md documents the intended path: migrate agents/ to thin wrappers that import from kb_agent_mcp.
